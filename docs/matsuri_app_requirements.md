# 祭りアプリ（神輿マッチング）要件整理（ドラフト）

## 1. アプリ概要（コンセプト）

- **アプリ名（仮）**: 祭り（Matsuri）
- **一言でいうと**:
  **「1回500円で、地方の祭りの神輿を担ぎに行けるマッチングアプリ」**
- スマホファーストの画面設計（レスポンシブ対応）


## 2. 背景・解決したい課題

- **地方の課題**
  - 人口減少・高齢化により、祭りの神輿の「担ぎ手」が不足している
  - 担ぎ手が集まらず、神輿を出せない・規模を縮小せざるを得ない状況

- **都会の個人（例: 東京のサラリーマン）の課題**
  - 地域との関わりや「コミュニティ参加」への興味はある
  - しかし、いきなり濃い人間関係に飛び込むのは抵抗がある
  - 参加方法が分かりづらく、1歩目を踏み出しにくい

- **このアプリで実現したいこと**
  - 都会の個人が、**1回500円を支払うだけで気軽に神輿を担げる**体験を提供する
  - 地方の祭り主催者が、**簡単に担ぎ手募集をかけられる**仕組みを提供する
  - これにより、
    - 地方: 人手不足の解消・祭り文化の維持
    - 都会の個人: 気軽で程よい距離感の「地域参加体験」
    を両立させる

## 3. 想定ユーザーとユースケース

### 3.1 担ぎ手（一般ユーザー）

- **プロフィール**
  - 例: 東京在住の会社員、学生など
  - 休日や有給を使って、どこかの祭りに参加してみたい

- **やりたいこと**
  - 行けるエリア・日付の祭りを簡単に探したい
  - アプリ上で500円を支払い、参加枠を確保したい
  - 集合時間・場所・持ち物などを事前にアプリで確認したい

### 3.2 祭り主催者

- **プロフィール**
  - 地方自治体、商店街、神社、町内会など

- **やりたいこと**
  - 自分たちの祭りイベントを登録したい
  - 担ぎ手募集（必要人数・日時・場所）を簡単に掲載したい
  - 応募状況・参加者リスト・支払い状況を確認したい

## 4. 画面モック（テキストイメージ）

### 4.1 担ぎ手向け画面

#### 4.1.1 トップ / 祭り検索画面

- **要素（イメージ）**
  - エリア入力
    - 都道府県
    - 市区町村
  - 日付選択
    - カレンダー or 日付ピッカー
  - 現在地からの距離フィルタ
    - 例: 〜10km / 〜50km / 指定なし
  - 検索ボタン
  - 検索結果リスト（カード形式）
    - 祭り名
    - 開催日・時間
    - 開催エリア
    - 募集残り人数
    - 料金: 500円/回

#### 4.1.2 祭り詳細画面

- **要素（イメージ）**
  - 祭り名
  - 写真（1枚以上）
  - 開催日時
  - 集合時間
  - 集合場所（住所 + 地図リンク）
  - 必要な服装・持ち物
  - 神輿の説明
    - 距離
    - 重さ（目安）
    - コースの概要
  - 募集人数 / 残り枠
  - 注意事項（安全・保険などの簡易説明）
  - 「この祭りに参加する（500円）」ボタン

#### 4.1.3 参加申込 / 決済画面

- **要素（イメージ）**
  - 参加対象の祭り情報（確認用）
  - 料金: 500円
  - 支払い方法選択（クレジットカード等）※具体サービスは今後検討
  - 利用規約・キャンセルポリシーの確認チェック
  - 「支払って参加を確定する」ボタン

#### 4.1.4 マイページ（担ぎ手）

- **要素（イメージ）**
  - プロフィール
    - 名前
    - アイコン
    - 居住エリア
  - 「これから参加予定の祭り」一覧
  - 「参加済みの祭り履歴」一覧
  - 支払い履歴
  - 獲得したバッジ一覧
    - どの祭りのバッジか（祭り名・開催年など）
    - バッジ画像・説明文
    - バッジの公開 / 非公開設定（プロフィール上での表示制御）

### 4.2 主催者向け画面

#### 4.2.1 主催者ダッシュボード

- **要素（イメージ）**
  - 自分が登録した祭り一覧
    - 開催前 / 開催済 などのステータス
  - 各祭りの募集状況
    - 募集人数 / 応募人数
  - 「新しい祭りを登録する」ボタン

#### 4.2.2 祭り登録 / 編集画面

- **要素（イメージ）**
  - 祭り名
  - 開催日・時間
  - 集合場所（住所・地図）
  - 募集人数
  - 参加条件（年齢・体力など）
  - 説明文
  - 写真アップロード
  - 公開 / 非公開設定
  - 「登録して募集を開始する」ボタン

#### 4.2.3 参加者一覧画面

- **要素（イメージ）**
  - 参加者名（ニックネーム）
  - 支払い済みステータス
  - 連絡用一斉メッセージ機能への入口
  - 当日受付用のチェックイン管理（参加済みフラグ）

#### 5.1.3 アカウント管理の基本方針

- 祭りの開催者（主催者）と祭りの参加者（担ぎ手）は、それぞれ別のアカウント種別として管理する。
- 主催者として新規登録したユーザーが「担ぎ手としてもアプリを使いたい」と希望した場合は、主催者アカウントの登録情報を元に、一般ユーザー用アカウント（`users` テーブル）のレコードをあとから作成する。
- 1人のユーザーが「主催者モード」と「参加者モード」をアプリ内でスイッチして切り替えられるようにする（同一人物に対して主催者アカウントと一般ユーザーアカウントの両方を紐づけるイメージ）。
